About

Welcome to my Jekyll website! This is a static website built with Jekyll and served using Docker containers.

What is Jekyll?

Jekyll is a static site generator that takes your content written in Markdown, processes it through templates, and generates a complete static website. It's perfect for blogs, documentation sites, and any content-focused website.

Why Docker?

Docker provides a consistent environment for building and serving the website. It ensures that the site works the same way regardless of where it's deployed, making it easy to move between development, staging, and production environments.

Features

  • Fast Performance: Static sites load quickly and are highly performant
  • Easy Deployment: Simple Docker commands to build and deploy
  • Version Control: All content and code is version controlled
  • Responsive Design: Works great on all devices
  • SEO Friendly: Built with SEO best practices in mind

Getting Started

To run this site locally for development:

docker-compose up jekyll-dev

To build and serve the production version:

docker-compose up jekyll-prod

Visit http://localhost:4000 for development or http://localhost for production.
