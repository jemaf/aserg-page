**Software**

- [DCL](http://rterrabh.github.io/DCL): domain-specific language for architecture conformance
- [APIMiner](http://apiminer.org/): instrumenting JavaDocs with source code examples
- [NextFlow](http://nextflow.org/): object-business process mapping framework
- [JMove](http://aserg.labsoft.dcc.ufmg.br/jmove): a move method recommendation system
- [RTTool](http://aserg.labsoft.dcc.ufmg.br/rttool): extracting relative thresholds for source code metrics
- [TopicViewer](https://code.google.com/p/topic-viewer/): a source code analysis using Semantic Clustering and Distribution Maps
- [NextBug](http://aserg.labsoft.dcc.ufmg.br/nextbug): next-good-bug recommender for Bugzilla
- [ModularityCheck](http://aserg.labsoft.dcc.ufmg.br/modularitycheck): assessing modularity using co-change clusters
- [JSClassFinder](https://github.com/aserg-ufmg/JSClassFinder): detecting classes in JavaScript
- [APISonar](http://apisonar.com): mining API usage examples

**Datasets**

- [ArgoUML-SPL](http://argouml-spl.tigris.org/): product line variant of ArgoUML
- [COMETS](http://aserg.labsoft.dcc.ufmg.br/comets): source code metrics time series
- [Qualitas.class](http://aserg.labsoft.dcc.ufmg.br/qualitas.class): compiled version of the Qualitas Corpus
- [APIMiner 2 Dataset](http://aserg.labsoft.dcc.ufmg.br/apiminer-dataset): Android API usage patterns
